# Описание предметной области

Предметная область — интернет-магазин, в котором нужно вести учёт заказов. Для этого создаётся информационная система. Система хранит информацию о товарах, заказах, пользователях. Покупатель может искать, просматривать товары и оформлять заказы, а администратор — добавлять, изменять и удалять данные. Система предназначена для хранения и обработки информации о продукции интернет-магазина.  
  
## Цели и задачи системы

•	Хранение информации о товарах: Хранить сведения о товарах в системе.  
•	Поиск товаров: Предоставить покупателю возможность выполнять поиск товаров.  
•	Оформление заказов: Предоставить покупателю возможность оформлять заказы в магазине.  
•	Управление данными: Предоставить администратору возможность добавлять, изменять и удалять данные.

## Пользователи системы (актёры) и их роли

1.	Администратор: Основной пользователь для ведения учёта. Управляет данными системы. Добавляет, редактирует и удаляет товары.
2.	Покупатель: Пользователь, «читающий» данные учёта, формирующий спрос. Просматривает и ищет товары, просматривает свою корзину, информацию о товарах и оформляет заказы.





## Основной функционал

•	Авторизация пользователя (ввод имени пользователя и пароля).  
•	Добавление нового товара: ввод карточки товара (название, описание, категория, цена, единицы измерения, штрихкод/артикул)  
•	Редактирование товара: изменение данных карточки товара.  
•	Удаление товара.  
•	Поиск и фильтрация товаров по названию, категории, цене, наличию, характеристикам.   
•	Просмотр карточки товара: описание, фото, цена, наличие, сроки поставки (если нет в наличии).  
•	Проверка наличия: отображение доступного количества и резервирование при добавлении в корзину.  
•	Оформление заказа: покупатель может добавлять товары в корзину и совершать заказ.

## Архитектура проекта
В системе используется классическая трёхуровневая архитектура. Система состоит из трёх основных частей:
1.	Слой интерфейса: Пользователь работает с системой через интерфейс. Здесь можно искать товары, просматривать информацию и выполнять другие действия.
2.	Слой бизнес-логики: Отвечает за основные действия системы. Проверяет данные и выполняет операции с товарами.
3.	Слой данных: Хранит информацию о товарах, заказах, пользователях.
